آموزش برنامه‌نویسی بک‌اند با Node.js

کامل‌ترین دوره بک‌اند در ایران — از اولین سرور تا استقرار روی سرور واقعی

backend — bash
$ npm init -y
$ npm i express prisma pg dotenv
✔ server listening on port 3000
$ docker compose up -d
✔ api live → api.spawn.academy
⏱ مدت دوره: ۴ ماه
📹 تعداد جلسات: ۶۴ ساعت
🏆 سطح: مقدماتی تا پیشرفته

در دوره آموزش مقدماتی بک‌اند با زبان Go (Golang)، قدم‌به‌قدم با مفاهیم اصلی توسعه بک‌اند آشنا می‌شوید؛ از مبانی برنامه‌نویسی و ساخت اولین برنامه Go تا طراحی API، کار با پایگاه داده و تست و امنیت پایه. هدف دوره این است که در کنار یادگیری مفاهیم، با انجام تمرین‌ها و ساخت یک پروژه عملی، درک درستی از نحوه کار بک‌اند و اجزای اصلی آن به دست بیاورید.

با روش تدریس پروژه‌محور ما، همزمان با یادگیری تئوری، دست به کد می‌شی و ۳ پروژه واقعی رو از صفر تا استقرار روی سرور پیش می‌بری. دیگه نگران مفاهیم خشک و انتزاعی نباش — اینجا همه‌چیز عملی و کاربردیه!
